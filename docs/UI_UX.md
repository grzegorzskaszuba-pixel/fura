# UI_UX

## Kierunek

- jasny, czysty, techniczny interfejs
- jeden ekran główny bez dashboardowych paneli
- mobile-first z pełnym działaniem na desktopie
- akcent kolorystyczny w pomarańczu na neutralnym tle bieli i zinc/slate

## Układ ekranu

- góra: profil po lewej, logo po prawej
- hero: duże zdjęcie aktywnego auta i karuzela
- opis auta: nazwa, parametry, tagi rejestracji i VIN
- podsumowanie: przebieg, następny serwis, ostatni serwis, koszty
- sekcja główna: przełącznik historia/plan
- lista wpisów: mobile timeline/lista bez tabeli
- dół: sticky footer z akcjami `Dodaj serwis` i `Zaplanuj serwis`

## Mobile

- formularze otwierane przez responsywny modal/drawer
- akcje główne stale dostępne na dole ekranu
- przełączanie aut i zakładek wspiera dotyk
